1 · Problem

Wann ist eine Zuordnung eine Funktion? Einstieg

Ein Kreis mit Radius 5 um den Ursprung erfüllt x² + y² = 25. Ist damit y eine Funktion von x?

Rechnet y für x = 3 aus.

9 + y² = 25, also y² = 16 und damit y = 4 oder y = −4. Zu einer x-Stelle gehören zwei y-Werte.

Warum ist das ein Problem?

Eine Funktion ordnet jedem x-Wert genau einen y-Wert zu. Der volle Kreis verletzt genau das — er ist kein Funktionsgraph. Am Bild sieht man es sofort: die Senkrechte bei x = 3 trifft ihn zweimal.

Wie rettet man die Sache?

Man entscheidet sich für eine Hälfte: f(x) = √25 − x² beschreibt den oberen Halbkreis, und zwar nur für −5 ≤ x ≤ 5. Zu einer Funktion gehört also nicht nur ein Term, sondern immer auch ein Definitionsbereich.

Zwei Gefäße werden mit gleichbleibendem Zufluss gefüllt: ein zylindrisches und ein kegelförmiges (Spitze unten). Skizziert jeweils die Füllhöhe h in Abhängigkeit von der Zeit t.

Zylinder — welcher Verlauf?

Der Querschnitt ist überall gleich groß, also kommt in gleichen Zeiten gleich viel Höhe dazu: eine Gerade durch den Ursprung.

Kegel mit der Spitze unten — welcher Verlauf?

Unten steckt in wenig Volumen viel Höhe, oben umgekehrt. Die Höhe wächst zuerst schnell und wird dann immer langsamer: eine gekrümmte, abflachende Kurve.

Woher wusstet das, obwohl keine einzige Zahl gegeben war?

Aus der Form des Graphen. Term, Tabelle, Graph und Wortbeschreibung sagen dasselbe — aber jede Darstellung zeigt etwas anderes zuerst. Darum geht es heute.

2 · Klärung

Klärung — Funktion, Definitionsbereich, Wertebereich

Eine Funktion ist erst vollständig angegeben, wenn Zuordnungsvorschrift und Definitionsbereich feststehen. Vier Schritte bringen das in Ordnung.

  1. Eindeutigkeit prüfenGehört zu jedem x genau ein y? Am Graphen: jede Senkrechte darf höchstens einen Punkt treffen (Senkrechten-Test). Zu einer Gleichung wie x² + y² = 25 gehört keine Funktion.
  2. Definitionsbereich bestimmenDrei Stolperstellen: Nenner ≠ 0, Radikand ≥ 0, Logarithmusargument > 0. Im Sachkontext kommt die Sachgrenze dazu (keine negative Zeit).
  3. Wertebereich bestimmenWelche y-Werte werden tatsächlich angenommen? Entweder am Verlauf ablesen oder die Gleichung f(x) = y nach x auflösen und sehen, für welche y das gelingt.
  4. Darstellung wechselnTerm → Tabelle → Graph → Worte. Der Term rechnet, die Tabelle zeigt Einzelwerte, der Graph zeigt den Verlauf, die Worte zeigen die Bedeutung. Keine Darstellung kann alles.

Zwei Funktionen sind erst dann gleich, wenn Term und Definitionsbereich übereinstimmen.

3 · Beispiel

Beispiel — vollständig vorgerechnet

Wurzelfunktion: f(x) = √x − 2 + 1

  1. x − 2 ≥ 0 ⟺ x ≥ 2Radikand darf nicht negativ werden → D = [2; ∞)
  2. √x − 2 ≥ 0die Wurzel liefert nie einen negativen Wert
  3. f(x) ≥ 1also W = [1; ∞), kleinster Wert bei x = 2
  4. f(2) = 1 · f(3) = 2 · f(6) = 3 · f(11) = 4Wertetabelle: die Schritte werden immer größer
  5. Graph: startet bei (2 | 1) und steigt immer flacherdieselbe Funktion, vierte Darstellung

Gebrochenrationale Funktion: g(x) = x + 1x − 3

  1. x − 3 ≠ 0 ⟺ x ≠ 3Nennernullstelle ausschließen → D = ℝ \ {3}
  2. g(0) = −13 · g(4) = 5 · g(5) = 3einige Werte zur Orientierung
  3. y = x + 1x − 3 ⟺ x + 1 = y(x − 3)nach x auflösen, um W zu finden
  4. x(1 − y) = −3y − 1 ⟹ x = 3y + 1y − 1das gelingt für jedes y ≠ 1
  5. W = ℝ \ {1}der Wert 1 wird nie angenommen — y = 1 ist die waagerechte Asymptote
4 · Merksatz

Merksatz — Funktionsbegriff und Darstellungsformen

  • Eine Funktion ordnet jedem x aus dem Definitionsbereich genau einen Wert zu.Senkrechten-Test: jede Senkrechte trifft den Graphen höchstens einmal
  • Zur Funktion gehört immer der Definitionsbereich — Nenner ≠ 0, Radikand ≥ 0, Logarithmusargument > 0.√x − 2: D = [2; ∞) · 1x − 3: D = ℝ \ {3}
  • Der Wertebereich enthält nur die tatsächlich angenommenen Werte.x + 1x − 3 nimmt jeden Wert außer 1 an: W = ℝ \ {1}
  • Term, Tabelle, Graph und Wortbeschreibung sind vier Sichten auf dieselbe Funktion.eine endliche Tabelle legt die Funktion aber nie fest

Typischer Fehler: „x² + y² = 25 ist eine Funktion, man kann ja y ausrechnen.“

Richtig: Man erhält zwei Werte: y = ±√25 − x². Erst die Einschränkung auf eine Hälfte, etwa f(x) = √25 − x² mit D = [−5; 5], ergibt eine Funktion.

Typischer Fehler: „D = ℝ, es steht ja nur ein x da.“

Richtig: Der Definitionsbereich hängt vom Bau des Terms ab, nicht von seiner Länge: h(x) = √x − 2 hat D = [2; ∞), obwohl der Term kurz ist.

Anforderungsbereich I — Reproduzieren · angeben, berechnen, ablesen
Aufgabe 1VorwärtsAFB I3 BE

Bestimmt die Nullstellen und den Scheitelpunkt von f(x) = x² − 4x + 3.

Selbstcheck: y-Koordinate des Scheitels?

Faktorisieren: x² − 4x + 3 = (x − 1)(x − 3) — Nullstellen 1 und 3. Der Scheitel liegt aus Symmetriegründen mittig: x = 2 und f(2) = 4 − 8 + 3 = −1, also S(2 | −1) (Tiefpunkt, denn a = 1 > 0).

Aufgabe 2VorwärtsAFB I3 BE

Der Definitionsbereich von f(x) = x² − 4x + 3 wird auf [0; 3] eingeschränkt. Gebt den größten und den kleinsten Funktionswert an, den f jetzt annimmt.

Selbstcheck: Größter Funktionswert auf [0; 3]?

Kandidaten sind die Randstellen und der Scheitel: f(0) = 3, f(3) = 0, f(2) = −1. Größter Wert 3 (bei x = 0), kleinster Wert −1 (bei x = 2). Der Wertebereich schrumpft von [−1; ∞) auf [−1; 3] — der Definitionsbereich verändert den Wertebereich mit.

Aufgabe 3RückwärtsAFB I3 BE

Gebt je eine Funktion an mit D = ℝ \ {2} und mit D = [3; ∞). Begründet eure Wahl.

Zum Beispiel f(x) = 1x − 2: der Nenner wird nur bei x = 2 null.
g(x) = √x − 3: der Radikand x − 3 ist genau ab x = 3 nicht negativ. Das Bauprinzip: die verbotene bzw. die Randstelle in den Nenner bzw. unter die Wurzel schreiben.

Aufgabe 4RückwärtsAFB I3 BE

Gebt eine Funktion mit W = [−2; ∞) an und begründet, dass ihr Wertebereich wirklich dieser ist.

Zum Beispiel f(x) = x² − 2. Es gilt x² ≥ 0, also f(x) ≥ −2, und der Wert −2 wird bei x = 0 angenommen. Jeder Wert y ≥ −2 tritt bei x = √y + 2 auf. Ebenso möglich: |x| − 2.

Anforderungsbereich II — Zusammenhänge herstellen · bestimmen, untersuchen, erläutern
Aufgabe 5VorwärtsAFB II3 BE

Gegeben sind die Terme f(x) = x² − 4, g(x) = 2^x, h(x) = 4 − x² und k(x) = x³ − 4x sowie drei Beschreibungen:

  1. Der Graph ist symmetrisch zur y-Achse und hat den Tiefpunkt (0 | −4).
  2. Der Graph ist punktsymmetrisch zum Ursprung und hat die Nullstellen −2, 0 und 2.
  3. Der Graph ist streng monoton wachsend und hat keine Nullstelle. Ordnet jeder Beschreibung den passenden Term zu und begründet, warum der übrig bleibende Term nicht zu Beschreibung (1) passt.

  1. → f: f(−x) = f(x), und der kleinste Wert ist f(0) = −4.
  2. → k: k(−x) = −k(x) und k(x) = x(x − 2)(x + 2) hat genau die Nullstellen −2, 0, 2.
  3. → g: 2^x > 0 für alle x, streng monoton wachsend, keine Nullstelle.
Übrig bleibt h: der Graph ist zwar y-achsensymmetrisch, hat aber den Hochpunkt (0 | 4) statt eines Tiefpunkts — er passt daher nicht zu (1).

Aufgabe 6VorwärtsAFB II3 BE

Bestimmt Definitions- und Wertebereich von g(x) = x + 1x − 3 und begründet, welcher Wert nicht angenommen wird.

Selbstcheck: Welcher y-Wert wird nie angenommen?

D = ℝ \ {3}, denn nur dort wird der Nenner null. Für den Wertebereich y = x + 1x − 3 nach x auflösen: x + 1 = y(x − 3), also x(1 − y) = −3y − 1 und x = 3y + 1y − 1. Das gelingt für jedes y ≠ 1, also W = ℝ \ {1}. Probe: y = 1 führt auf x + 1 = x − 3, also auf 1 = −3 — unlösbar.

Aufgabe 7RückwärtsAFB II3 BE

Der Graph einer quadratischen Funktion f verläuft durch die Punkte (0 | 8), (2 | 0) und (4 | 0). Begründet zunächst ohne Rechnung, welche x-Koordinate der Scheitelpunkt hat, und ermittelt dann eine Funktionsgleichung von f.

Ohne Rechnung: der Scheitel liegt auf der Symmetrieachse, also mittig zwischen den Nullstellen 2 und 4 — damit x_S = 3.
Nullstellenform f(x) = a(x − 2)(x − 4); Einsetzen von (0 | 8): a·(−2)·(−4) = 8a = 8, also a = 1 und f(x) = x² − 6x + 8. Probe: f(3) = 9 − 18 + 8 = −1 — der Scheitel ist S(3 | −1).

Aufgabe 8ParameterAFB II3 BE

Für welches a hat f_a(x) = √x − a den Definitionsbereich [−3; ∞)? Bestimmt außerdem den Definitionsbereich von g_a(x) = 1x² − a in Abhängigkeit von a.

Selbstcheck: Wert von a im ersten Teil?

Erster Teil: x − a ≥ 0 ⟺ x ≥ a, also a = −3.
Zweiter Teil: der Nenner wird null, wenn x² = a. Für a < 0 gibt es keine Lösung, also D = ℝ. Für a = 0 ist D = ℝ \ {0}. Für a > 0 ist D = ℝ \ {−√a, √a}.

Aufgabe 9ParameterAFB II3 BE

Gegeben ist f_a(x) = ax − 1 + 2. Zeigt, dass der Wert 2 für kein a ≠ 0 angenommen wird, und gebt den Wertebereich in Abhängigkeit von a an.

f_a(x) = 2 würde ax − 1 = 0 bedeuten; ein Bruch ist nur null, wenn sein Zähler null ist — für a ≠ 0 unmöglich. Der Term ax − 1 durchläuft für x ∈ ℝ \ {1} alle Werte außer 0, also W = ℝ \ {2}. Sonderfall a = 0: dann ist f konstant 2 und W = {2}.

Aufgabe 10BeurteilenAFB II3 BE

Beurteilt: „Nennt eine Wertetabelle zu jeder x-Stelle genau einen y-Wert, so gehört sie zu einer Funktion — und sie legt diese Funktion fest.“

Der erste Teil ist wahr (Eindeutigkeit ist genau die Funktionsbedingung), der zweite falsch. Gegenbeispiel: Die Tabelle (1 | 1), (2 | 4), (3 | 9) passt zu f(x) = x², aber ebenso zu g(x) = x² + (x − 1)(x − 2)(x − 3), denn der Zusatzterm ist an den drei Stellen null. Außerhalb unterscheiden sie sich: f(0) = 0, aber g(0) = 0 + (−1)·(−2)·(−3) = −6.

Anforderungsbereich III — Verallgemeinern und beurteilen · begründen, beurteilen, entwickeln
Aufgabe 11VorwärtsAFB III4 BE

Bestimmt den Wertebereich von f(x) = xx² + 1 exakt und begründet euer Vorgehen.

Der Nenner ist stets positiv, also D = ℝ. Ansatz y = xx² + 1 liefert y·x² − x + y = 0. Für y = 0 ist x = 0 eine Lösung. Für y ≠ 0 ist das quadratisch in x; eine reelle Lösung gibt es genau dann, wenn die Diskriminante 1 − 4y² ≥ 0 ist, also y² ≤ 14. Damit W = [−12; 12]. Probe: f(1) = 12 und f(−1) = −12 — die Randwerte werden angenommen.

Aufgabe 12BeurteilenAFB III4 BE

Beurteilt die folgenden Aussagen; begründet wahre allgemein und widerlegt falsche durch ein konkretes Gegenbeispiel oder eine allgemeine Begründung.

  1. „Ist der Graph einer auf ganz ℝ definierten Funktion f punktsymmetrisch zum Ursprung und ist 2 eine Nullstelle von f, dann ist auch −2 eine Nullstelle.“
  2. „Jede auf ganz ℝ definierte Funktion, deren Graph symmetrisch zur y-Achse ist, nimmt an der Stelle 0 ihren größten oder ihren kleinsten Funktionswert an.“
  3. „Es gibt eine Funktion, deren Graph die y-Achse in zwei verschiedenen Punkten schneidet.“

  1. wahr: Punktsymmetrie bedeutet f(−x) = −f(x), also f(−2) = −f(2) = −0 = 0.
  2. falsch: f(x) = x⁴ − 2x² ist y-achsensymmetrisch, aber f(0) = 0 ist weder größter noch kleinster Wert — es gilt f(1) = f(−1) = −1 < 0 und f(2) = 8 > 0.
  3. falsch: nach der Definition einer Funktion gehört zu x = 0 genau ein Funktionswert; der Graph trifft die y-Achse also höchstens einmal.

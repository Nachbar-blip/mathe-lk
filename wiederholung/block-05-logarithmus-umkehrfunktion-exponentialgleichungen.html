Logarithmusfunktionen

log_b(x) beantwortet: Mit welchem Exponenten wird b zu x? Umkehrfunktion von bˣ.

Typischer Fehler: log(a + b) ist NICHT log a + log b. Nur Produkte werden zu Summen: log(a·b) = log a + log b.

Logarithmusgleichung: Exponenzieren

  1. Den Logarithmus allein stellen: ln(x − 3) = 2.
  2. Beide Seiten als Exponent zur Basis e: x − 3 = e².
  3. Auflösen: x = e² + 3 ≈ 10,39.
  4. Definitionsbereich prüfen: x − 3 > 0, also x > 3 — die Lösung liegt darin ✓.

Umkehrfunktionen

Existiert nur, wenn f streng monoton (umkehrbar) ist — sonst den Definitionsbereich einschränken.

Typischer Fehler: f⁻¹ ist NICHT 1f. Die Hochstellung meint die Umkehrung, nicht den Kehrwert.

Umkehrfunktion bestimmen — zwei Schritte

  1. Funktionsgleichung mit y schreiben: f(x) = 2x + 3 wird zu y = 2x + 3.
  2. Schritt 1 — x und y tauschen: x = 2y + 3.
  3. Schritt 2 — nach y umstellen: x − 3 = 2y, also y = x − 32.
  4. Ergebnis aufschreiben: f⁻¹(x) = x − 32.
  5. Probe: f⁻¹(f(x)) = 2x + 3 − 32 = x ✓ — kommt x heraus, stimmt die Umkehrung.

1 · Problem

Die Unbekannte steckt im Exponenten Einstieg

In Block 04 blieb eine Frage offen: Nach wie vielen Jahren hat sich ein Kapital bei 6 % Verzinsung verdoppelt? Antwortet exakt, nicht durch Probieren.

Stellt die Gleichung auf.

200 · 1,06^t = 400, also nach Kürzen 1,06^t = 2. Der Startwert spielt keine Rolle.

Warum hilft Umformen nicht weiter?

Die Unbekannte steht im Exponenten. Weder Umstellen noch Wurzelziehen holt sie herunter — Probieren liefert nur „zwischen 11 und 12“.

Was bräuchte man?

Eine Rechenart, die das Potenzieren rückgängig macht und den Exponenten herausholt. Genau das ist der Logarithmus: t = log₁,₀₆(2) = ln 2 / ln 1,06 ≈ 11,90.

Was ist log₂(8), log₂(1), log₂(0,5) — und was ist log₂(0)?

Die ersten drei.

2³ = 8 ⟹ log₂(8) = 3 · 2⁰ = 1 ⟹ log₂(1) = 0 · 2^(−1) = 0,5 ⟹ log₂(0,5) = −1. Der Logarithmus ist der gesuchte Exponent.

Und log₂(0)?

Es gibt kein x mit 2^x = 0, denn Potenzen von 2 sind stets positiv. log₂(0) existiert nicht — ebenso wenig der Logarithmus einer negativen Zahl.

Was heißt das für den Definitionsbereich?

D = (0; ∞). Das ist kein Zufall: der Logarithmus ist die Umkehrfunktion der Exponentialfunktion, und aus deren Wertebereich (0; ∞) wird der Definitionsbereich der Umkehrung.

2 · Klärung

Klärung — Logarithmus, Umkehrfunktion, Exponentialgleichungen

Exponentialgleichungen löst man in einer festen Reihenfolge — und logarithmiert erst ganz am Schluss.

  1. IsolierenErst die Potenz allein auf eine Seite bringen: Summanden auf die andere Seite, danach durch den Vorfaktor teilen. Vorher zu logarithmieren, führt in die Irre.
  2. Logarithmierenb^x = c mit c > 0 wird zu x = log_b(c) = ln c / ln b. Der Rechner kennt nur ln und lg — daher der Basiswechsel.
  3. Logarithmusgesetze nutzenln(u·v) = ln u + ln v · ln(uv) = ln u − ln v · ln(u^r) = r·ln u. Das dritte Gesetz ist das entscheidende: es holt den Exponenten herunter.
  4. Umkehrfunktion bestimmenGleichung y = f(x) nach x auflösen, danach x und y vertauschen. Definitions- und Wertebereich tauschen dabei die Rollen; der Graph entsteht durch Spiegelung an y = x.

Logarithmieren darf man, sobald beide Seiten positiv sind — und immer nur die ganze Seite, nie einzelne Summanden.

3 · Beispiel

Beispiel — vollständig vorgerechnet

Exponentialgleichung: 5 · 3^x − 7 = 38

  1. 5 · 3^x = 45zuerst die 7 auf die andere Seite
  2. 3^x = 9durch den Vorfaktor 5 teilen — jetzt steht die Potenz allein
  3. 3^x = 3² ⟹ x = 2gleiche Basis, also gleiche Exponenten
  4. x = ln 9 / ln 3 = 2derselbe Weg mit dem Logarithmus
  5. 5 · 9 − 7 = 38Probe ✓

Umkehrfunktion: f(x) = 2·e^(3x) + 1, D = ℝ

  1. y = 2e^(3x) + 1 ⟹ y − 12 = e^(3x)die Potenz isolieren
  2. 3x = ln(y − 12)beide Seiten logarithmieren
  3. x = (13)·ln(y − 12)nach x aufgelöst
  4. f⁻¹(x) = (13)·ln(x − 12)x und y vertauschen
  5. D(f⁻¹) = W(f) = (1; ∞), W(f⁻¹) = ℝProbe: f(0) = 3 und f⁻¹(3) = (13)·ln 1 = 0 ✓
4 · Merksatz

Merksatz — Logarithmus und Umkehrfunktion

  • log_b(c) ist der Exponent, mit dem man b potenzieren muss, um c zu erhalten.b^x = c ⟺ x = log_b(c), nur für c > 0
  • Basiswechsel: log_b(c) = ln c / ln b.log₁,₀₆(2) = ln 2 / ln 1,06 ≈ 11,90
  • Die drei Gesetze: Produkt wird Summe, Quotient wird Differenz, Exponent wird Faktor.ln(u^r) = r · ln u holt die Unbekannte herunter
  • Umkehrfunktion: auflösen, vertauschen — D und W tauschen die Rollen.der Graph entsteht durch Spiegelung an der Geraden y = x

Typischer Fehler: „ln(u + v) = ln u + ln v.“

Richtig: Gilt nicht. Probe mit u = 2, v = 8: ln 10 ≈ 2,30, aber ln 2 + ln 8 = ln 16 ≈ 2,77. Das Gesetz gilt für das Produkt, nicht für die Summe.

Typischer Fehler: „5 · 3^x = 45, also 15^x = 45.“

Richtig: Der Faktor 5 steht vor der Potenz, nicht in der Basis. Erst durch 5 teilen: 3^x = 9.

Anforderungsbereich I — Reproduzieren · angeben, berechnen, ablesen
Aufgabe 1VorwärtsAFB I3 BE

Löst exakt:

  1. e^(x−7) = 1,
  2. 2^x = 18.

Selbstcheck: Lösung von Teil (a)?

  1. e^0 = 1, und e^u nimmt jeden Wert höchstens einmal an — also x − 7 = 0 und x = 7.
  2. 18 = 2^(−3), gleiche Basis, also x = −3. Beide Male kommt man ohne Taschenrechner aus, weil beide Seiten dieselbe Basis tragen.

Aufgabe 2VorwärtsAFB I3 BE

Löst exakt: 3^x = 81 und 5 · 2^x = 40.

Selbstcheck: Lösung von 3^x = 81?

81 = 3⁴, also x = 4.
Bei der zweiten Gleichung zuerst den Vorfaktor beseitigen: 2^x = 8 = 2³, also x = 3. Der Faktor 5 gehört nicht in die Basis.

Aufgabe 3RückwärtsAFB I3 BE

Gebt eine Exponentialgleichung an, deren Lösung x = 3 ist, und eine Logarithmusgleichung mit derselben Lösung.

Zum Beispiel 2^x = 8 (denn 2³ = 8) und log₂(x + 5) = 3 (denn 2³ = 8 = 3 + 5). Bauprinzip: von der gewünschten Lösung rückwärts rechnen.

Aufgabe 4RückwärtsAFB I3 BE

Gebt eine Funktion an, deren Definitionsbereich (2; ∞) ist und deren Umkehrfunktion ganz ℝ als Definitionsbereich hat.

Zum Beispiel f(x) = ln(x − 2): das Argument muss positiv sein, also D = (2; ∞); der Logarithmus durchläuft alle reellen Zahlen, also W = ℝ. Da D(f⁻¹) = W(f) ist, hat die Umkehrfunktion f⁻¹(x) = e^x + 2 den Definitionsbereich ℝ.

Anforderungsbereich II — Zusammenhänge herstellen · bestimmen, untersuchen, erläutern
Aufgabe 5VorwärtsAFB II3 BE

Löst 4^x − 5·2^x + 4 = 0 vollständig und begründet euren Ansatz.

Selbstcheck: Größere der beiden Lösungen?

Der Schlüssel ist 4^x = (2²)^x = (2^x)². Substitution u = 2^x (beachten: u > 0): u² − 5u + 4 = 0 liefert u = 4 und u = 1. Rücksubstitution: 2^x = 4 ⟹ x = 2 und 2^x = 1 ⟹ x = 0. Beide u-Werte sind positiv, also sind beide brauchbar. Probe: 16 − 20 + 4 = 0 ✓ und 1 − 5 + 4 = 0 ✓.

Aufgabe 6VorwärtsAFB II3 BE

Ein Bestand verdoppelt sich alle 5 Jahre; er wird durch B(t) = B₀ · 2t5 beschrieben. Ermittelt exakt, nach welcher Zeit sich der Bestand verdreifacht hat, und gebt das Ergebnis zusätzlich auf Zehntel gerundet an.

Selbstcheck: Gerundeter Wert in Jahren?

Ansatz B₀ · 2t5 = 3·B₀; der Startwert kürzt sich heraus: 2t5 = 3. Logarithmieren: t5 = ln 3 / ln 2, also exakt t = 5 · ln 3 / ln 2. Mit dem Rechner: t ≈ 7,9 Jahre. Plausibel: nach 5 Jahren ist es das Doppelte, nach 10 Jahren das Vierfache — das Dreifache liegt dazwischen.

Aufgabe 7RückwärtsAFB II3 BE

Bestimmt die Umkehrfunktion von f(x) = 2·e^(3x) + 1 samt ihrem Definitions- und Wertebereich.

Auflösen: y − 1 = 2e^(3x), y − 12 = e^(3x), 3x = ln(y − 12), x = (13)·ln(y − 12). Vertauschen: f⁻¹(x) = (13)·ln(x − 12). Wegen W(f) = (1; ∞) ist D(f⁻¹) = (1; ∞) und W(f⁻¹) = D(f) = ℝ. Probe: f(0) = 3, f⁻¹(3) = (13)·ln 1 = 0 ✓.

Aufgabe 8ParameterAFB II3 BE

  1. Für welches a hat a · 2^x = 40 die Lösung x = 3?
  2. Für welche a besitzt a
2^x = 40 überhaupt eine Lösung?

  1. a · 2³ = 40, also 8a = 40 und a = 5.
  2. Umformen zu 2^x = 40a. Da 2^x nur positive Werte annimmt, ist die Gleichung genau dann lösbar, wenn 40a > 0 ist, also für a > 0. Für a ≤ 0 gibt es keine Lösung.

Aufgabe 9ParameterAFB II3 BE

Gegeben ist f_a(x) = ln(x − a). Gebt Definitionsbereich und Nullstelle in Abhängigkeit von a an und beschreibt, wie sich der Graph mit a verändert.

Das Argument muss positiv sein: x − a > 0, also D = (a; ∞). Nullstelle: ln(x − a) = 0 ⟺ x − a = 1, also x = a + 1. Der Graph ist der um a nach rechts verschobene Graph von ln x; die senkrechte Asymptote wandert mit auf x = a. Die Form bleibt unverändert.

Aufgabe 10BeurteilenAFB II3 BE

Beurteilt: „Für alle a, b > 0 gilt ln(a + b) = ln a + ln b.“

Falsch. Gegenbeispiel a = b = 1: links ln 2 ≈ 0,693, rechts ln 1 + ln 1 = 0. Ein zweites: a = 2, b = 8 gibt links ln 10 ≈ 2,303, rechts ln 16 ≈ 2,773. Richtig lautet das Gesetz ln(a · b) = ln a + ln b — es macht aus einem Produkt eine Summe. Für Summen gibt es keine Regel.

Anforderungsbereich III — Verallgemeinern und beurteilen · begründen, beurteilen, entwickeln
Aufgabe 11VorwärtsAFB III4 BE

Löst 3·e^(2x) = 12 exakt und vereinfacht das Ergebnis mit einer Logarithmusregel. Leitet anschließend die allgemeine Lösungsformel für b^x = c (mit b > 0, b ≠ 1, c > 0) her und begründet, dass es genau eine Lösung gibt.

Isolieren: e^(2x) = 4. Logarithmieren: 2x = ln 4, also x = ln 4 / 2. Mit ln(u^r) = r·ln u ist ln 4 = ln(2²) = 2·ln 2, also x = ln 2.
Allgemein: aus b^x = c folgt durch Logarithmieren beider Seiten ln(b^x) = ln c, wegen ln(b^x) = x·ln b also x = ln c / ln b (erlaubt, da ln b ≠ 0 für b ≠ 1).
Genau eine Lösung: b^x ist streng monoton (wachsend für b > 1, fallend für b < 1) und nimmt jeden Wert aus (0; ∞) an — also wird jeder zulässige Wert c genau einmal getroffen.

Aufgabe 12BeurteilenAFB III4 BE

Beurteilt; begründet wahre Aussagen allgemein und widerlegt falsche durch ein konkretes Gegenbeispiel oder eine allgemeine Begründung.

  1. „Für alle a, b > 0 gilt ln(a · b) = ln a + ln b.“
  2. „Für jede reelle Zahl c hat die Gleichung 2^x = c genau eine Lösung.“
  3. „Der Graph der Umkehrfunktion entsteht aus dem Graphen von f durch Spiegelung an der x-Achse.“

  1. wahr: schreibt man a = e^u und b = e^v, so ist a·b = e^(u+v) und damit ln(a·b) = u + v = ln a + ln b. Das ist das Potenzgesetz, von der anderen Seite gelesen.
  2. falsch: für c ≤ 0 gibt es keine Lösung, denn 2^x > 0 für alle x; etwa 2^x = −8 ist unlösbar (2^(−3) = 18, nicht −8). Nur für c > 0 gibt es genau eine.
  3. falsch: gespiegelt wird an der Winkelhalbierenden y = x. Eine Spiegelung von e^x an der x-Achse ergäbe −e^x (überall negativ), die Umkehrfunktion ist aber ln x.

Die Klassen im Einzelnen

Lineare Funktionenf(x) = m·x + n
Definitionsbereich
D = ℝ — jede reelle Zahl ist einsetzbar.
Wertebereich
W = ℝ für m ≠ 0; für m = 0 ist W = {n} (waagerechte Gerade).
Monotonie
m > 0 streng monoton steigend, m < 0 streng monoton fallend, m = 0 konstant.
Symmetrie
Punktsymmetrisch zum y-Achsenabschnitt (0|n). Nur für n = 0 ungerade Funktion.
Nullstellen
m ≠ 0: genau eine bei x = −n/m. m = 0, n ≠ 0: keine. m = n = 0: alle.

m ist die Steigung (Höhenunterschied je Schritt nach rechts), n der y-Achsenabschnitt.

Steigung aus zwei Punkten: m = (y₂−y₁)/(x₂−x₁) — die Differenzen nicht vertauschen und x/y nicht verwechseln.

Geradengleichung aus zwei Punkten

  1. Gegeben A(1|1) und B(3|5). Steigung zuerst: m = (y₂ − y₁)/(x₂ − x₁) = (5 − 1)/(3 − 1) = 4/2 = 2.
  2. Einen Punkt in y = mx + n einsetzen: 1 = 2·1 + n → n = −1.
  3. Ergebnis: y = 2x − 1. Probe mit dem zweiten Punkt: 2·3 − 1 = 5 ✓.

Nullstelle und Schnittpunkt zweier Geraden

  1. Nullstelle: y = 0 setzen, also 2x − 1 = 0 → x = 1/2.
  2. Schnittpunkt zweier Geraden: Terme gleichsetzen. 2x − 1 = −x + 5 → 3x = 6 → x = 2.
  3. x in eine der beiden Gleichungen einsetzen: y = 2·2 − 1 = 3, Schnittpunkt S(2|3).
  4. Parallel (gleiches m) → kein Schnittpunkt. Senkrecht → m₁ · m₂ = −1.

Quadratische Funktionenf(x) = ax² + bx + c
Definitionsbereich
D = ℝ.
Wertebereich
Mit Scheitel S(d|e): a > 0 → W = [e; ∞), a < 0 → W = (−∞; e].
Monotonie
Nicht global monoton. a > 0: fallend bis d, danach steigend (umgekehrt für a < 0).
Symmetrie
Achsensymmetrisch zur Geraden x = d. Nur für b = 0 zur y-Achse (gerade Funktion).
Nullstellen
Erst die Diskriminante prüfen — das ist der Term unter der Wurzel: D = b² − 4ac (bzw. (p/2)² − q). D > 0 zwei Nullstellen, D = 0 eine (doppelte), D < 0 keine. Rechenwege: siehe Reiter Rechenweg.

Scheitelform f(x) = a(x − d)² + e liest Scheitel und Wertebereich direkt ab.

Erst das Vorzeichen der Diskriminante prüfen, dann die Wurzel ziehen — aus einem negativen Term unter der Wurzel wird keine Lösung, nicht etwa null. Zweiter Klassiker: in der Scheitelform ist das Vorzeichen von d gespiegelt, a(x − 3)² hat den Scheitel bei x = +3.

pq-Formel — braucht die Normalform x² + px + q = 0

  1. Durch a teilen, bis vor dem x² eine 1 steht. Aus 2x² − 4x − 6 = 0 wird x² − 2x − 3 = 0.
  2. Ablesen: p = −2, q = −3.
  3. Zuerst die Diskriminante, also den Term unter der Wurzel: (p/2)² − q = (−1)² − (−3) = 1 + 3 = 4.
  4. Vorzeichen prüfen: 4 > 0, also gibt es zwei Lösungen. Erst jetzt die Wurzel ziehen: √4 = 2.
  5. Einsetzen: x₁,₂ = −p/2 ± 2 = 1 ± 2, also x₁ = 3 und x₂ = −1.

abc-Formel (Mitternachtsformel) — geht ohne Umformen

  1. Direkt aus f(x) = ax² + bx + c ablesen: a = 1, b = −2, c = −3.
  2. Diskriminante zuerst: D = b² − 4ac = (−2)² − 4·1·(−3) = 4 + 12 = 16.
  3. D > 0 → zwei Lösungen, √16 = 4.
  4. x₁,₂ = (−b ± √D)/(2a) = (2 ± 4)/2, also x₁ = 3 und x₂ = −1.
  5. Vorteil: kein Teilen durch a nötig. Nachteil: mehr Zahlen im Kopf.

Quadratische Ergänzung — der Weg zur Scheitelform

  1. Ziel: aus x² − 2x − 3 die Form (x − d)² + e machen.
  2. Die Hälfte des x-Koeffizienten bilden und quadrieren: (−2/2)² = 1. Das ist die Ergänzung.
  3. Diese 1 addieren und sofort wieder abziehen — der Term ändert sich dadurch nicht: x² − 2x + 1 − 1 − 3.
  4. Die ersten drei Glieder sind ein Binom: (x − 1)² − 1 − 3 = (x − 1)² − 4.
  5. Scheitel direkt ablesen: S(1|−4). Nullstellen: (x − 1)² = 4 → x − 1 = ±2 → x = 3 oder x = −1.
  6. Bei a ≠ 1 vorher a ausklammern: 2x² − 4x = 2(x² − 2x).

Ohne Formel: Faktorisieren

  1. Fehlt das absolute Glied, reicht Ausklammern: x² − 3x = x(x − 3) → x = 0 oder x = 3.
  2. Satz vom Nullprodukt: Ein Produkt ist null, wenn ein Faktor null ist.
  3. Bei ganzzahligen Lösungen hilft der Satz von Vieta: x₁ + x₂ = −p und x₁ · x₂ = q. Für x² − 2x − 3 sucht man zwei Zahlen mit Summe 2 und Produkt −3 — das sind 3 und −1.

Kubische & Potenzfunktionenf(x) = a·xⁿ
Definitionsbereich
D = ℝ für n ∈ ℕ. Bei negativem Exponenten (x⁻ⁿ = 1/xⁿ) ist x = 0 ausgeschlossen.
Wertebereich
n ungerade: W = ℝ. n gerade: W = [0; ∞) für a > 0.
Monotonie
n ungerade, a > 0: auf ganz ℝ streng monoton steigend. n gerade: erst fallend, dann steigend.
Symmetrie
Der Exponent entscheidet: gerades n → achsensymmetrisch, ungerades n → punktsymmetrisch.
Nullstellen
Nur x = 0, mit Vielfachheit n. Gerade Vielfachheit = berühren, ungerade = schneiden.

Bei ganzrationalen Funktionen bestimmen Grad und Leitkoeffizient den Globalverlauf.

Vielfachheit übersehen: (x−2)² hat bei x = 2 eine Berührstelle, keinen Vorzeichenwechsel.

Nullstellen ganzrationaler Funktionen — in dieser Reihenfolge

  1. Ausklammern, wenn kein absolutes Glied da ist: x³ − 4x = x(x² − 4) → x = 0 oder x² = 4.
  2. Satz vom Nullprodukt anwenden: x = 0, x = 2, x = −2.
  3. Substitution bei nur geraden Exponenten: x⁴ − 5x² + 4 = 0 mit u = x² wird zu u² − 5u + 4 = 0 → u = 1, u = 4; zurück: x = ±1, x = ±2.
  4. Polynomdivision, wenn beides nicht geht: eine Nullstelle raten (Teiler des absoluten Glieds probieren), dann durch (x − x₀) teilen und den Rest mit der pq-Formel lösen.

Was der Exponent über den Graphen verrät

  1. Grad ungerade → die Enden laufen in verschiedene Richtungen, es gibt mindestens eine Nullstelle.
  2. Grad gerade → beide Enden laufen in dieselbe Richtung, es kann gar keine Nullstelle geben.
  3. Leitkoeffizient negativ → alles spiegelt sich an der x-Achse.
  4. Höchstens so viele Nullstellen wie der Grad angibt.

Wurzelfunktionenf(x) = √x
Definitionsbereich
D = [0; ∞) — unter der Wurzel darf nichts Negatives stehen. Bei √(x−a) gilt x ≥ a.
Wertebereich
W = [0; ∞). Die Wurzel liefert nie einen negativen Wert.
Monotonie
Auf ganz D streng monoton steigend, aber immer langsamer (Rechtskrümmung).
Symmetrie
Keine — der Graph existiert nur auf einer Seite.
Nullstellen
Genau eine dort, wo der Radikand null wird; bei √x also x = 0.

√x ist die Umkehrfunktion von x² für x ≥ 0 — Spiegelung an der Winkelhalbierenden y = x.

√(x²) = |x|, nicht x. Für negative x liefert die Wurzel den Betrag.

Wurzelgleichung lösen — Probe ist Pflicht

  1. Wurzel allein auf eine Seite bringen: √(x + 6) = x.
  2. Beide Seiten quadrieren: x + 6 = x².
  3. Umstellen und mit der pq-Formel lösen: x² − x − 6 = 0 → x₁ = 3, x₂ = −2.
  4. Probe einsetzen, denn Quadrieren ist keine Äquivalenzumformung: √(3 + 6) = 3 ✓, aber √(−2 + 6) = 2 ≠ −2 ✗.
  5. Nur x = 3 ist Lösung. x = −2 ist eine Scheinlösung.

Definitionsbereich vorher bestimmen

  1. Der Radikand darf nicht negativ werden: bei √(2x − 4) also 2x − 4 ≥ 0.
  2. Auflösen: x ≥ 2, also D = [2; ∞).
  3. Lösungen außerhalb von D fallen weg — auch wenn die Rechnung sie liefert.

Sinus & Kosinusf(x) = a·sin(b(x − c)) + d
Definitionsbereich
D = ℝ.
Wertebereich
W = [d − |a|; d + |a|]. Ohne Parameter: [−1; 1].
Monotonie
Periodisch abwechselnd steigend und fallend — nie global monoton.
Symmetrie
sin ist punktsymmetrisch zum Ursprung (ungerade), cos achsensymmetrisch zur y-Achse (gerade).
Nullstellen
Unendlich viele im Abstand einer halben Periode: sin bei k·π, cos bei π/2 + k·π.

a Amplitude · Periode 2π/b · c Verschiebung nach rechts · d Mittellinie.

b streckt nicht die Amplitude, sondern staucht die Periode: sin(2x) schwingt doppelt so schnell, nicht doppelt so hoch.

Alle Lösungen von sin x = c finden

  1. Eine Lösung mit dem Taschenrechner: sin x = 0,5 → x₁ = arcsin(0,5) = π/6.
  2. Die zweite Lösung im Periodenfenster liegt symmetrisch: x₂ = π − π/6 = 5π/6.
  3. Alle weiteren durch Anhängen der Periode: x = π/6 + k·2π und x = 5π/6 + k·2π, k ∈ ℤ.
  4. Bei cos x = c ist die zweite Lösung x₂ = −x₁, ebenfalls + k·2π.
  5. Der Rechner liefert immer nur EINE Lösung — die anderen muss man selbst ergänzen.

Exponentialfunktionenf(x) = a·bˣ
Definitionsbereich
D = ℝ.
Wertebereich
W = (0; ∞) für a > 0 — der Graph erreicht die x-Achse nie.
Monotonie
b > 1 streng monoton steigend (Wachstum), 0 < b < 1 streng monoton fallend (Zerfall).
Symmetrie
Keine.
Nullstellen
Keine. bˣ ist immer positiv — erst eine Verschiebung wie bˣ − 2 erzeugt eine.

Multiplikatives Wachstum: pro Schritt nach rechts wird mit b multipliziert, nicht addiert.

Die x-Achse ist Asymptote, nicht Nullstelle: der Graph nähert sich beliebig an, berührt sie aber nie.

Exponentialgleichung: Logarithmieren

  1. Die Potenz allein stellen: 3 · 2ˣ = 48 → 2ˣ = 16.
  2. Beide Seiten logarithmieren: x · ln 2 = ln 16.
  3. Nach x auflösen: x = ln 16 / ln 2 = 4.
  4. Im hilfsmittelfreien Teil exakt stehen lassen — ln 16/ln 2 ist eine Lösung, kein Dezimalwert nötig.
  5. Gleiche Basis erkennen ist schneller: 2ˣ = 2⁴ → x = 4.

Logarithmusfunktionenf(x) = log_b(x)
Definitionsbereich
D = (0; ∞) — nur echt positive Zahlen. Bei ln(x−3) gilt x > 3.
Wertebereich
W = ℝ.
Monotonie
b > 1: streng monoton steigend, aber immer langsamer.
Symmetrie
Keine.
Nullstellen
Genau eine bei x = 1, denn b⁰ = 1 für jede Basis.

log_b(x) beantwortet: Mit welchem Exponenten wird b zu x? Umkehrfunktion von bˣ.

log(a + b) ist NICHT log a + log b. Nur Produkte werden zu Summen: log(a·b) = log a + log b.

Logarithmusgleichung: Exponenzieren

  1. Den Logarithmus allein stellen: ln(x − 3) = 2.
  2. Beide Seiten als Exponent zur Basis e: x − 3 = e².
  3. Auflösen: x = e² + 3 ≈ 10,39.
  4. Definitionsbereich prüfen: x − 3 > 0, also x > 3 — die Lösung liegt darin ✓.

Die Logarithmusgesetze

  1. Produkt wird Summe: log(a · b) = log a + log b. Beispiel: ln(3x) = ln 3 + ln x.
  2. Quotient wird Differenz: log(a/b) = log a − log b. Beispiel: ln(x/5) = ln x − ln 5.
  3. Exponent wird Faktor: log(aⁿ) = n · log a. Das ist das wichtigste Gesetz — damit holt man die Unbekannte aus dem Exponenten herunter.
  4. Kehrwert: log(1/a) = −log a. Folgt aus dem Quotientengesetz mit log 1 = 0.
  5. Wurzel: log(ⁿ√a) = (1/n) · log a. Wurzel ist eine Potenz mit Bruchexponent.
  6. Feste Werte: log_b(1) = 0 und log_b(b) = 1 — für jede Basis. Also ln 1 = 0, ln e = 1.
  7. Hin und zurück: b^(log_b(x)) = x und log_b(b^x) = x — Logarithmieren und Potenzieren heben sich auf.
  8. Basiswechsel: log_b(x) = ln x / ln b. Damit rechnet jeder Taschenrechner jede Basis, auch wenn er nur ln und lg kennt.

Die drei Schreibweisen

  1. ln x = log_e(x), der natürliche Logarithmus zur Basis e — der Standard in der Analysis.
  2. lg x = log₁₀(x), der Zehnerlogarithmus — in Sachkontexten (pH-Wert, Dezibel).
  3. log₂ x, der Zweierlogarithmus — bei Verdopplungsfragen.
  4. Alle drei folgen denselben Gesetzen; nur die Basis unterscheidet sie.

Was NICHT gilt — die häufigsten Fallen

  1. log(a + b) ist nicht log a + log b. Für Summen gibt es kein Gesetz.
  2. log(a · b) ist nicht log a · log b — aus dem Produkt wird eine Summe.
  3. (log a)ⁿ ist nicht n · log a. Nur der Exponent im Argument darf nach vorn.
  4. log(a/b) ist nicht log a / log b — aus dem Quotienten wird eine Differenz.
  5. Logarithmen von 0 oder negativen Zahlen gibt es nicht: ln 0 und ln(−2) sind nicht definiert.

Die e-Funktionf(x) = eˣ
Definitionsbereich
D = ℝ.
Wertebereich
W = (0; ∞).
Monotonie
Auf ganz ℝ streng monoton steigend, weil e ≈ 2,718 > 1.
Symmetrie
Keine.
Nullstellen
Keine — eˣ > 0 für alle x.

Die e-Funktion ist ihre eigene Ableitung: f′(x) = eˣ. Deshalb ist sie die Basis der Analysis.

e ist eine feste Zahl (≈ 2,718), keine Variable — eˣ wird nicht wie eine Potenzfunktion abgeleitet.

Gleichungen mit eˣ lösen

  1. e-Potenz allein stellen: 5·eˣ − 10 = 0 → eˣ = 2.
  2. Beide Seiten mit ln: x = ln 2. Exakt stehen lassen, nicht runden.
  3. Produkt: bei x·eˣ = 0 nutzt man eˣ ≠ 0 — nur x = 0 bleibt übrig.
  4. Das ist der häufigste Fall in Klausuren: eˣ wird nie null, also liefert nur der andere Faktor Nullstellen.

Umkehrfunktionenf⁻¹ mit f⁻¹(f(x)) = x
Definitionsbereich
D von f⁻¹ ist der Wertebereich von f — die Bereiche tauschen die Rollen.
Wertebereich
W von f⁻¹ ist der Definitionsbereich von f.
Monotonie
f⁻¹ hat dasselbe Monotonieverhalten wie f.
Symmetrie
Der Graph von f⁻¹ entsteht durch Spiegelung von f an der Winkelhalbierenden y = x.
Nullstellen
Die Nullstelle von f⁻¹ ist der y-Achsenabschnitt von f — die Koordinaten tauschen.

Existiert nur, wenn f streng monoton (umkehrbar) ist — sonst den Definitionsbereich einschränken.

f⁻¹ ist NICHT 1/f. Die Hochstellung meint die Umkehrung, nicht den Kehrwert.

Umkehrfunktion bestimmen — zwei Schritte

  1. Funktionsgleichung mit y schreiben: f(x) = 2x + 3 wird zu y = 2x + 3.
  2. Schritt 1 — x und y tauschen: x = 2y + 3.
  3. Schritt 2 — nach y umstellen: x − 3 = 2y, also y = (x − 3)/2.
  4. Ergebnis aufschreiben: f⁻¹(x) = (x − 3)/2.
  5. Probe: f⁻¹(f(x)) = (2x + 3 − 3)/2 = x ✓ — kommt x heraus, stimmt die Umkehrung.

Wenn der Definitionsbereich eingeschränkt werden muss

  1. f(x) = x² ist auf ganz ℝ nicht umkehrbar: 2 und −2 haben beide den Wert 4.
  2. Erst den Definitionsbereich einschränken, sodass f streng monoton wird: x ≥ 0.
  3. Dann wie gehabt: y = x² → tauschen: x = y² → nach y umstellen: y = √x.
  4. Die Einschränkung mitschreiben: f⁻¹(x) = √x für x ≥ 0.
  5. Kontrolle am Graphen: f und f⁻¹ liegen spiegelbildlich zur Geraden y = x.

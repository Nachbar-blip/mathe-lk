Block 08 · Verhalten im Unendlichen, Grenzwertbegriff

Mathematik LK (eA) · Ziel: Grenzverhalten qualitativ erschließen und begründen, lim-Schreibweise nutzen, Dominanz-Hierarchie kennen.

Tasten: B Beamer · Pfeile Abschnitt · L Lösungen

1 · Problem

Wohin läuft das? Einstieg

Wohin läuft f(x) = 4 − 1x, wenn x immer größer wird?

Rechnet drei Werte aus: x = 10, x = 100, x = 1000.

3,9 · 3,99 · 3,999 — die Werte rücken an die 4 heran.

Wird die 4 irgendwann erreicht?

Nein. 1x wird beliebig klein, aber nie null — für jedes x bleibt ein Rest. Die Werte stabilisieren sich bei 4, ohne sie anzunehmen.

Von welcher Seite nähern sie sich?

Für x > 0 ist 1x > 0, also f(x) = 4 − (etwas Positives) < 4 — von unten. Für diese Art von Aussage brauchen wir eine eigene Schreibweise.

Was ist f(∞) für f(x) = 4 − 1x?

Setzt ein.

Das geht nicht. ∞ ist keine Zahl und keine Stelle — man kann sie nicht einsetzen.

Trotzdem sieht man am Graphen, dass sich etwas einpendelt. Was fehlt also?

Ein Begriff für „wohin die Werte laufen“, ohne dass man irgendwo einsetzt. Genau das leistet der Grenzwert.

Wie schreibt man ihn?

limx → ∞ f(x) = 4, gesprochen „Limes von f(x) für x gegen unendlich gleich 4“. Die Definition beantwortet damit eine Frage, die das Einsetzen offenlässt.

2 · Klärung

Klärung — Definition und Schreibweise

Aus der Beobachtung wird ein Begriff — und eine Schreibweise, die ohne Einsetzen auskommt.

  1. Definition: Grenzwert für x → ∞Nähern sich die Funktionswerte f(x) für unbegrenzt wachsendes x beliebig genau einer festen Zahl g, so heißt g der Grenzwert von f für x gegen unendlich. Man sagt: f konvergiert gegen g.
  2. Schreibweiselimx → ∞ f(x) = g — gesprochen „Limes von f(x) für x gegen unendlich gleich g“. Beispiel: limx → ∞ (4 − 1x) = 4.
  3. Der linke Rand: x → −∞Dieselbe Frage für beliebig kleine (negative) x — eigenes Symbol, eigene Rechnung: limx → −∞ f(x). Beispiel: limx → −∞ (4 − 1x) = 4, diesmal von oben, denn für x < 0 ist 1x < 0.
  4. Wenn es keine Zahl gibtWachsen die Werte über jede Schranke, schreibt man limx → ∞ f(x) = ∞ (oder −∞). Das ist kein Grenzwert im Sinn der Definition — ∞ ist keine Zahl —, sondern eine Kurzschrift für „unbeschränkt“. Man sagt: f divergiert.

Ein Grenzwert ist eine Zahl, die man nicht einsetzt, sondern der man sich nähert. Beide Ränder, x → ∞ und x → −∞, werden getrennt untersucht.

3 · Beispiel

Beispiel — ganzrationale Funktionen mit lim-Ansatz

Ganzrational, rechter Rand: f(x) = −3x⁵ + 20x³

  1. limx → ∞ f(x) = limx → ∞ (−3x⁵ + 20x³)Ansatz: lim davor, Term dahinter
  2. = limx → ∞ x⁵·(−3 + 20x²)höchste Potenz ausklammern
  3. 20x² → 0, Klammer → −3der Rest verschwindet
  4. x⁵ → ∞, also x⁵·(−3) → −∞Ergebnis: limx → ∞ f(x) = −∞

…und getrennt davon der linke Rand: x → −∞

  1. limx → −∞ f(x) = limx → −∞ x⁵·(−3 + 20x²)gleicher Ansatz, anderer Rand
  2. Klammer → −3der Rest verschwindet auch hier
  3. x⁵ → −∞ (ungerader Exponent), also (−∞)·(−3) → +∞Ergebnis: limx → −∞ f(x) = +∞

Gerader Grad: g(x) = 2x⁴ − 5x + 1

  1. limx → ∞ g(x) = limx → ∞ x⁴·(2 − 5x³ + 1x⁴) = +∞Klammer → 2, x⁴ → ∞
  2. limx → −∞ g(x) = limx → −∞ x⁴·(2 − 5x³ + 1x⁴) = +∞x⁴ ist an beiden Rändern positiv — beide Ränder gleich
3 · Beispiel

Jetzt ihr — zwei ganzrationale Funktionen

Beide Ränder, jeweils mit lim-Ansatz und ausgeklammerter höchster Potenz.

Übung 1Vorwärts

Bestimmt limx → ∞ f(x) und limx → −∞ f(x) für f(x) = 4x³ − x² + 7.

limx → ∞ f(x) = limx → ∞ x³·(4 − 1x + 7x³) = +∞ (Klammer → 4, x³ → ∞). limx → −∞ f(x) = limx → −∞ x³·(4 − 1x + 7x³) = −∞ (Klammer → 4, x³ → −∞).

Übung 2Vorwärts

Bestimmt limx → ∞ g(x) und limx → −∞ g(x) für g(x) = −x⁴ + 10x² − 3. Warum sind beide Ergebnisse gleich?

limx → ∞ g(x) = limx → ∞ x⁴·(−1 + 10x² − 3x⁴) = −∞ und ebenso limx → −∞ g(x) = −∞. Der Exponent 4 ist gerade, x⁴ ist also an beiden Rändern positiv; das Minus des Leitkoeffizienten dreht beides nach unten.

4 · Merksatz

Merksatz — Grenzwert und ganzrationale Funktionen

  • Ein Grenzwert ist die Zahl, der sich f(x) für x → ∞ beliebig nähert — man setzt nicht ein, man nähert sich.limx → ∞ f(x) = g
  • Beide Ränder sind zwei Rechnungen: x → +∞ und x → −∞ getrennt ansetzen.limx → ∞ f(x) und limx → −∞ f(x)
  • Ganzrational: höchste Potenz ausklammern — allein sie entscheidet. Das Ergebnis ist immer +∞ oder −∞.f(x) = −3x⁵ + 20x³: limx → ∞ f(x) = limx → ∞ x⁵·(−3 + 20x²) = −∞
  • Vorzeichen: Leitkoeffizient a mal Verhalten von xⁿ. Gerader Grad: beide Ränder gleich. Ungerader Grad: entgegengesetzt.gerader Grad, a > 0: links und rechts +∞
    gerader Grad, a < 0: links und rechts −∞
    ungerader Grad, a > 0: links −∞, rechts +∞
    ungerader Grad, a < 0: links +∞, rechts −∞

Typischer Fehler: ∞ − ∞ = 0

Richtig: ∞ − ∞ ist keine Zahl, sondern ein Wettrennen: x² − x → ∞, aber (x + 1) − x → 1.

3 · Beispiel

Gebrochenrational — Zählergrad gegen Nennergrad

Erst wie gehabt — ausklammern: g(x) = 2x + 5x − 1

  1. limx → ∞ g(x) = limx → ∞ x·(2 + 5x)x·(1 − 1x)höchste Potenz in Zähler und Nenner ausklammern
  2. = limx → ∞ 2 + 5x1 − 1xx kürzen
  3. = 21 = 2die Reste verschwinden; waagerechte Asymptote y = 2
  4. Beobachtung: nur die höchsten Potenzen und ihre Koeffizienten überleben.Darum genügt ab jetzt der Vergleich von Zählergrad (ZG) und Nennergrad (NG).

Fall 1 · ZG < NG: h(x) = 5x − 2x² + 1

  1. limx → ∞ h(x) = limx → ∞ x·(5 − 2x)x²·(1 + 1x²)ausklammern
  2. = limx → ∞ 1x·5 − 2x1 + 1x²kürzen — ein 1x bleibt übrig
  3. = 0 · 51 = 0der Nenner gewinnt; waagerechte Asymptote y = 0 (x-Achse)
  4. limx → −∞ h(x) = 0auch links: 1x → 0

Fall 2 · ZG = NG: k(x) = 3x² − 4x² + 1

  1. limx → ∞ k(x) = limx → ∞ x²·(3 − 4x²)x²·(1 + 1x²)ausklammern
  2. = limx → ∞ 3 − 4x²1 + 1x² = 31 = 3kürzen; Quotient der Leitkoeffizienten
  3. waagerechte Asymptote y = 3, ebenso für x → −∞Probe: k(100) = 29 99610 001 ≈ 2,9997

Fall 3 · ZG > NG: m(x) = x² + 1x

  1. limx → ∞ m(x) = limx → ∞ x²·(1 + 1x²)x = limx → ∞ x·(1 + 1x²) = +∞der Zähler gewinnt — kein Grenzwert, keine waagerechte Asymptote
  2. limx → −∞ m(x) = −∞links kippt das Vorzeichen mit x
  3. m(x) = x + 1xZähler durch Nenner teilen: Abstand zur Geraden y = x ist 1x → 0 — schräge Asymptote y = x
4 · Merksatz

Merksatz — gebrochenrationale Funktionen und Asymptoten

  • Rezept für jede gebrochenrationale Funktion: höchste Potenz in Zähler und Nenner ausklammern, kürzen — alle Terme der Form cxⁿ gehen gegen 0. Übrig bleibt einer von drei Fällen.cxⁿ → 0 für x → ±∞
  • Zählergrad < Nennergrad: der Nenner wächst schneller, die Werte gehen gegen 0. Die x-Achse ist waagerechte Asymptote.f(x) = 5x − 2x² + 1: limx → ∞ f(x) = 0 und limx → −∞ f(x) = 0 → Asymptote y = 0
  • Zählergrad = Nennergrad: nach dem Kürzen bleibt der Quotient der Leitkoeffizienten. Waagerechte Asymptote y = ab, an beiden Rändern dieselbe.f(x) = 3x² − 4x² + 1: limx → ∞ f(x) = 31 = 3 und limx → −∞ f(x) = 3 → Asymptote y = 3
  • Zählergrad > Nennergrad: der Zähler gewinnt, es gibt keinen Grenzwert — die Werte laufen gegen +∞ oder −∞, das Vorzeichen wie bei ganzrationalen Funktionen. Keine waagerechte Asymptote; ist der Zählergrad genau um 1 größer, gibt es eine schräge (Zähler durch Nenner teilen).f(x) = x² + 1x = x + 1x: limx → ∞ f(x) = +∞, limx → −∞ f(x) = −∞ → schräge Asymptote y = x
  • Asymptote heißt: eine Gerade, an die sich der Graph für x → ∞ oder x → −∞ immer enger anschmiegt. Es gibt drei Sorten.waagerecht, z. B. y = 3
    schräg, z. B. y = x
    senkrecht, z. B. x = 1 an einer Nullstelle des Nenners (das ist Block 09)

Typischer Fehler: „x = 0 einsetzen liefert den Grenzwert.“

Richtig: f(0) ist der y-Achsenabschnitt. Der Grenzwert fragt nach riesigen x — dort zählen nur die höchsten Potenzen.

Typischer Fehler: „Eine Asymptote darf der Graph nie berühren.“

Richtig: Doch — eine Asymptote beschreibt das Verhalten am Ende, sie ist keine Schranke für einzelne Stellen. Ob ein Graph seine waagerechte Asymptote trifft, ist eine Frage an den konkreten Term (Aufgabe 12).

Anforderungsbereich I — Reproduzieren · angeben, berechnen, ablesen
Aufgabe 1VorwärtsAFB I3 BE

Gebt das Verhalten von f(x) = 3 − 2x für x → +∞ an und begründet ohne Rechner, warum sich der Graph der Geraden y = 3 von unten nähert.

Selbstcheck: Grenzwert für x → +∞?

2x → 0, also f(x) → 3. Zur Richtung: für x > 0 ist 2x > 0, von 3 wird also stets etwas Positives abgezogen — damit ist f(x) < 3 für alle x > 0, der Graph bleibt unterhalb der Geraden und nähert sich ihr von unten. (Für x < 0 wäre es umgekehrt: dort läge der Graph oberhalb.)

Aufgabe 2VorwärtsAFB I3 BE

Bestimmt das Verhalten von p(x) = −2x³ + 50x für x → +∞ und x → −∞. Erklärt, warum der Summand 50x am Ende keine Rolle spielt.

x → +∞: p(x) → −∞ · x → −∞: p(x) → +∞. Ausklammern: x³·(−2 + 50x²) — die Klammer stabilisiert sich bei −2, das Vorzeichen macht x³. Der lineare Summand wächst nur linear und geht im Vergleich unter.

Aufgabe 3RückwärtsAFB I3 BE

Gebt je eine Funktion an, deren Werte für x → +∞ gegen 5 streben — einmal mit Annäherung von unten, einmal von oben.

Von unten z. B. f(x) = 5 − 1x, von oben z. B. g(x) = 5 + 1x. Entscheidend ist das Vorzeichen des Restterms; jede Funktion der Bauart 5 ± cxⁿ mit c > 0 leistet dasselbe.

Aufgabe 4RückwärtsAFB I3 BE

Gebt eine ganzrationale Funktion an, die für x → +∞ und für x → −∞ gegen −∞ läuft. Begründet eure Wahl.

Zum Beispiel f(x) = −x² oder f(x) = −x⁴ + 3. Nötig ist ein gerader Grad mit negativem Leitkoeffizienten: Bei geradem Exponenten liefern beide Richtungen dasselbe Vorzeichen, das Minus dreht es nach unten.

Anforderungsbereich II — Zusammenhänge herstellen · bestimmen, untersuchen, erläutern
Aufgabe 5VorwärtsAFB II3 BE

Untersucht g(x) = 3x − 1x + 2 für x → ±∞ und gebt die Gleichung der waagerechten Asymptote an.

Selbstcheck: Grenzwert von g für x → ∞?

Durch x kürzen: 3 − 1x1 + 2x → 31 = 3. Waagerechte Asymptote y = 3 für beide Richtungen. Probe: g(100) = 299102 ≈ 2,93.

Aufgabe 6VorwärtsAFB II3 BE

Gegeben ist h(x) = 4x² − 1x² + 1. Ermittelt das Verhalten für x → ±∞ sowie den y-Achsenabschnitt und begründet, dass der Graph achsensymmetrisch ist.

Mit x² kürzen: 4 − 1x²1 + 1x² → 4 — Asymptote y = 4. h(0) = −11 = −1. Symmetrie: x kommt nur in geraden Potenzen vor, also h(−x) = h(x).

Aufgabe 7RückwärtsAFB II3 BE

Gebt eine gebrochenrationale Funktion an, deren Graph die waagerechte Asymptote y = −3 besitzt und die an der Stelle 1 nicht definiert ist.

Zum Beispiel f(x) = −3xx − 1. Für x → ±∞ kürzt sich x heraus: −31 − 1x → −3. Der Nenner wird bei x = 1 null — dort ist f nicht definiert. Ebenso möglich: f(x) = −3 + 2x − 1.

Aufgabe 8ParameterAFB II3 BE

Für welchen Wert von a besitzt fa(x) = a·x − 1x + 2 die waagerechte Asymptote y = 3? Begründet.

Selbstcheck: Wert von a?

Zähler- und Nennergrad sind gleich, also ist der Grenzwert der Quotient der Leitkoeffizienten: a1 = a. Aus a = 3 folgt die Asymptote y = 3. Die Konstanten −1 und +2 beeinflussen den Grenzwert nicht.

Aufgabe 9ParameterAFB II3 BE

Gegeben ist die Schar fa(x) = x² + ax² + 1. Zeigt, dass für jedes a die Gerade y = 1 waagerechte Asymptote ist, und bestimmt, für welche a der Graph vollständig oberhalb dieser Asymptote verläuft.

Kürzen mit x²: 1 + ax²1 + 1x² → 1 für jedes a. Umformen: fa(x) = 1 + a − 1x² + 1. Da x² + 1 > 0 ist, liegt der Graph genau dann oberhalb, wenn a − 1 > 0, also für a > 1.

Aufgabe 10BeurteilenAFB II3 BE

Beurteilt: „Eine ganzrationale Funktion dritten Grades kann keine waagerechte Asymptote besitzen.“

Wahr. Klammert man x³ aus, bleibt x³·(a + bx + cx² + dx³); die Klammer stabilisiert sich beim Leitkoeffizienten a ≠ 0, und x³ wächst unbeschränkt. Das Produkt läuft also gegen ±∞ und kann sich keiner Zahl nähern. Allgemein gilt das für jede ganzrationale Funktion vom Grad ≥ 1 — nur konstante Funktionen haben eine waagerechte Asymptote, nämlich sich selbst.

Anforderungsbereich III — Verallgemeinern und beurteilen · begründen, beurteilen, entwickeln
Aufgabe 11VorwärtsAFB III4 BE

Begründet ohne Grenzwertkalkül, dass q(x) = x²2x für x → +∞ gegen 0 strebt, obwohl der Zähler unbeschränkt wächst.

Wertevergleich: bei x = 10 steht 100 gegen 1024, bei x = 20 schon 400 gegen 1 048 576. Der Nenner verdoppelt sich bei jedem Schritt um 1, der Zähler wächst nur polynomial — der Vorsprung wird beliebig groß, der Bruch also beliebig klein. Das ist die Dominanz-Hierarchie.

Aufgabe 12BeurteilenAFB III4 BE

Beurteilt die folgenden Aussagen (jeweils für x → ∞); begründet wahre allgemein und widerlegt falsche durch ein Gegenbeispiel.

  1. Gilt f(x) → ∞ und g(x) → ∞, so folgt f(x) − g(x) → 0.
  2. Eine Funktion mit waagerechter Asymptote y = 2 nimmt den Wert 2 nirgends an.
  3. Gilt f(x) → 3, so folgt f(x)² → 9.

  1. falsch: f(x) = x² und g(x) = x laufen beide gegen ∞, aber x² − x → ∞. Mit f(x) = x + 1 und g(x) = x käme 1 heraus — der Ausdruck ist unbestimmt.
  2. falsch: f(x) = 2 + xx² + 1 hat den Grenzwert 2 und dennoch f(0) = 2. Eine Asymptote beschreibt das Verhalten am Ende; über einzelne Stellen sagt sie nichts.
  3. wahr: nach dem Produktsatz ist f·f → 3·3 = 9.
